## Cara Menjalankan Proyek (Setup Lokal)
Ikuti langkah-langkah berikut untuk menjalankan notebook analisis di komputer lokal Anda menggunakan VS Code:

### 1. Kloning Repositori
Buka terminal Anda dan jalankan perintah berikut:
```bash
git clone https://github.com/shafhan-farizi/ajojing.git
cd ajojing
```

### 2. Instalasi Pustaka (Requirements)
Pastikan Anda sudah menginstal Python, lalu instal semua pustaka pendukung yang diperlukan melalui file `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 3. Menjalankan Notebook

1. Buka folder proyek ini di **VS Code**.

2. Masuk ke folder `notebooks/` dan buka file `.ipynb` yang ingin dijalankan.

3. Pilih **Kernel Python** di pojok kanan atas VS Code.

4. Klik **Run All** atau jalankan sel kode satu per satu.
